## Highlights ⭐️

* **Default code highlighting meets WCAG AAA**: the default `github` theme used syntect's InspiredGitHub colours, drawn for another background. On the `<pre>` box comments measured 2.73:1 and tags 2.85:1, and dark mode left light rules behind (`.code` at 1.34:1). ssg now ships its own palette, every token colour at least 7.3:1 on its box in both modes, and the tests measure each one. A syntect theme a site names is still used as-is.
* **Dependencies**: `model2vec-rs` 0.4 for the opt-in `model2vec` search feature, `@playwright/test` 1.65.0 for the visual tests, `docker/login-action` 4.8.0.
