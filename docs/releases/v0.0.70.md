## Highlights ⭐️

* **XML Feed Parsing and Generation via `oxml` 0.0.13**: `audit::gates::feeds` and `plugins::postprocess::atom` now parse RSS 2.0 and Atom 1.0 feeds with `oxml` 0.0.13 (`parse_str` and `Document::into_serialized`).
* **Homebrew, Scoop, and WinGet Packaging Rendered from Release Checksums**: `scripts/render-packaging.sh` populates `ssg.rb`, `ssg.json`, and `ssg.winget.yaml` directly from the release archive SHA-256 digests and attaches them to every GitHub release.
* **Accessibility and Security Advisory Fixes**: Clears the `label-content-name-mismatch` axe-core violation on `nav-search` buttons across 174 localized templates (#817) and updates `pulldown-cmark` to 0.13.6 (`RUSTSEC-2026-0414`) and `tokio` to 1.54.1 (`RUSTSEC-2026-0386`) in both workspaces.
