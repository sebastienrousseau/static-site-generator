## Highlights ⭐️

* **One path-containment rule**: the CLI path check, the CSS `url()` resolver and `fs_ops::is_path_within_root` now share `safe_join` and `is_within` from `euxis-commons` 0.0.9 (feature `path` only, no dependencies of its own) instead of three hand-rolled copies.
* **CSS `url()` can no longer climb out and back in**: a URL such as `css/../../site/x.png` used to resolve to a manifest entry when the site directory was named `site`. A URL that climbs above the site directory at any point is now left as written.
* **Dotted names are accepted**: files such as `a..b.md` or `v1..v2` were refused as path traversal because the check looked for the substring `..`. It now looks at path components, so only a real `..` that climbs out is refused.
* **Dependency updates**: `toml` 1.1.8 to 1.2.0 (#830) and `github/codeql-action` 4.39.2 to 4.39.3 (#831).
