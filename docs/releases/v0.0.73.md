## Highlights ⭐️

* **Symlink loops no longer hang a build**: a content directory with a symlink back to one of its ancestors used to return every file again at each level, or never finish with two such links. Each directory is now entered once, and symlinked content from elsewhere still builds (#826).
* **Highlighted code is coloured again**: `highlight.css` now carries token colours for the classes mdx-gen emits, scoped under `pre.highlight`, with a light and a dark palette (#822). A plain `<pre>` earlier on the page no longer stops later blocks being highlighted (#823).
* **CSS math survives aligned whitespace**: `minify_css` keeps the space either side of `+` and `-` in runs of spaces, so `clamp(1.25rem,   1.125rem  + 0.5556vw, 1.625rem)` no longer ships as the invalid `1.125rem+ 0.5556vw`.
* **`ssg-a11y` checks rules inside `@layer`**: the 2.5.8 target-size and 2.4.13 focus-appearance checks now see rules in cascade layers, while conditional blocks such as `@media print` inside a layer are still ignored.
