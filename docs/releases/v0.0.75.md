## Highlights ⭐️

* **Decorative images pass the alt-text check**: an image marked `alt="" aria-hidden="true"` was reported as `[1.1.1] <img> missing alt text`, and the `[llm]` plugin filled its empty `alt` with generated text. The accessibility check and the `[ai]` and `[llm]` plugins now share one rule, `ssg_a11y::img_missing_alt`: a missing `alt` is still an error, an empty one is accepted on an image marked decorative.
* **Unquoted attributes and quoted `>` read correctly**: an unquoted `alt=photo`, as minifiers write it, is no longer taken for an empty `alt`, and a `>` inside a quoted `src` no longer cuts the `[ai]` plugin's tag scan short.
* **CI lints every workspace member and target**: the clippy steps covered only the `ssg` crate, which is how errors built up unseen in the other crates, benches and integration tests. CI now runs `make lint`, the same command as the local gate.
* **Release pages complete on publish**: the release workflow now titles each release `ssg <version>` and writes the highlights, What's Changed, the SHA-256 of every asset and the Full Changelog link itself, so pages no longer need correcting by hand as v0.0.73 and v0.0.74 did.
