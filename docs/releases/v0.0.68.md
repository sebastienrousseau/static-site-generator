## Highlights ⭐️

* **YAML alias bombs are refused**: front matter and `data/*.yml` files now parse with noyalib 0.0.56, which enforces its alias budgets. A 576-byte document that expanded to 3.4 MB of JSON under v0.0.67 is now rejected like any malformed YAML (RUSTSEC-2026-0333).
* **Pages full of email addresses build again**: Markdown renders through comrak 0.55, so a page with thousands of bare email addresses no longer overflows the stack and aborts the build (GHSA-xg9p-p4jc-c46g).
* **Open Graph tags follow the protocol**: they now render as `<meta property="og:...">`, meta tag values escape `&`, `<` and `>`, JSON front matter no longer shows up as a page's first paragraph, and front matter after a byte order mark is read instead of failing the build.
* **Nightly benchmark figures get published**: the nightly run commits its figures to the `benchmark-results` branch, because `main` accepts changes only through pull requests.
