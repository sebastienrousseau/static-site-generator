## Highlights ⭐️

* **Rust 1.89 is now the minimum**: ssg needs Rust 1.89.0 or newer (was 1.88.0), recorded as ADR-0010. No dependency needs it; the MSRV and beta CI legs now build on the toolchain they name instead of on stable.
* **Hostile input is refused, not amplified**: a 576-byte YAML alias bomb in front matter or `data/*.yml` that expanded to 3.4 MB of JSON under v0.0.67 is rejected (noyalib 0.0.56, RUSTSEC-2026-0333), and a page with thousands of bare email addresses no longer overflows the stack (comrak 0.55, GHSA-xg9p-p4jc-c46g). rustls 0.23.46 and ammonia 4.1.7 clear six newer advisories.
* **Open Graph tags follow the protocol**: they now render as `<meta property="og:...">`, meta tag values escape `&`, `<` and `>`, JSON front matter no longer shows up as a page's first paragraph, and front matter after a byte order mark is read instead of failing the build.
* **Builds stop filling the temp directory**: since v0.0.45 every build left a full copy of the site's content under the system temp directory. The copy is now removed when the compile step finishes, whether it succeeded or failed.
