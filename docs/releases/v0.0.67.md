## Highlights ⭐️

* **Fingerprinted assets no longer break pages**: SRI attributes now go only on `<script src>` and stylesheet or preload `<link>` tags, and every other reference is renamed in place. A fingerprinted path inside JSON-LD, an `og:image` or an `<img>` no longer produces invalid JSON or bogus attributes.
* **Minified JavaScript runs as written**: the minifier now copies string, template and regex literals byte for byte and keeps the line breaks that end a statement. Values such as an IntersectionObserver `rootMargin` of `0px 0px -10% 0px` survive, and `var a = {}` followed by `foo()` on the next line stays valid.
* **`ssg audit` reads JSON-LD correctly next to HTML comments**: a `<script>` tag quoted inside a comment no longer opens a phantom block, so pages with valid JSON-LD stop being reported as unparseable.
* **Releases publish in one pass**: the crates.io publish step now waits for the provenance job that creates the release page, instead of racing it and failing.
